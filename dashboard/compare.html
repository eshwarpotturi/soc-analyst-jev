Signature WAF vs Jev

A rule-based WAF matches known attack shapes — SQL syntax, <script>, ../. It is strong there. But a new class of attack carries no signature: prompt injection against an app's AI, requests that ask it to leak data, and business-logic abuse. These read as ordinary text. This is the same set of requests through both.
