# SOC Analyst Agent (Jev)

A reverse proxy that classifies incoming HTTP requests as attacks (allow/block) using
[Jev](https://openrouter.ai/typesafe/jev-1.13), TypeSafe's structured decision model,
plus a static dashboard that replays a logged run.

Status: under construction. See `docs/plans/2026-09-29-soc-analyst-jev.md`.
